# School Canteen Daily Lunch Budget Evaluation

## Project Overview
This project is a simplified daily lunch budget evaluator developed to meet the requirements for **Computer Science 2, Quarter 1 AA**. It is specifically designed to help **PSHS-BRC** scholars to manage their daily expenses and avoid overspending before the school week ends. 

## Features
- **Budget and Cost Entrry**:
  Accepts user inputs for daily allowance, meal cost, and/or drink and snack cost.
- **Automated Calculator**:
  Adds up the the total cost and updates the remaining balance. 
- **Final Balance Evaluator**:
  Uses a simple `if-else` statement to evaluate the balance and then display a success message or an overspending warning.

## Inputs Needed
1. Daily Allowance in Philippine peso (Php).
2. Price of lunch meal.
3. Additional canteen expenses, or `0` if none.

## Planned Outputs
1. Combined price of meal and drink.
2. Leftover cash after expenses.
3. Display status message.

## How to Run
1. Open the program in Pycharm, VS Code, or Google Colab.
2. Run the program.
3. Enter the needed the values.
4. Check the status message displayed on the screen.
